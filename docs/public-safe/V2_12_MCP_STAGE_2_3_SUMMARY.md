# V2.12 MCP And Stage 2/3 Summary

MCP and platform integrations are treated as controlled capabilities, not automatic actions.

Potential capability groups include:

- GitHub repository operations
- Drive storage pointers
- analytics and search behavior review
- ad platform research and validation
- SEO, AEO, and GEO research support
- creative and video generation support
- reporting and dashboard support

## Required Gates

Before any connector action, the private system must record:

- route class
- privacy class
- source quality
- tool quality
- expected decision impact
- budget stop rule
- storage target
- approval reference when required

Public examples may describe capability groups, but they must not contain connector routes, connector logs, connector results, account identifiers, or private exports.
