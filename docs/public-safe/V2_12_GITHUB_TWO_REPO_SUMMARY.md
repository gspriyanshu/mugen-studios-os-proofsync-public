# V2.12 GitHub Two-Repository Summary

The GitHub model separates private coordination from public execution.

The private coordination side keeps planning, source authority, governance, and sensitive records. The public execution side keeps sanitized validators, examples, summaries, and future website shell work only after the right gates are met.

## Public Repository Role

The public repository is:

- a validation surface
- a public-safe example surface
- a future website execution shell
- a portfolio-safe summary surface after approval

The public repository is not:

- the private source authority
- a vault for raw evidence
- a service-readiness authority
- a place for connector logs
- a place for private account data

## Change Control

Changes use protected pull requests, validation checks, public-safety scans, and phase records. Direct main changes remain blocked by policy.
