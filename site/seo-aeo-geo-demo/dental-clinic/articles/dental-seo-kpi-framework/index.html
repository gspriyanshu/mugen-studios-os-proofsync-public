Dental SEO KPI Framework: Eligibility, Local Visibility, Enquiries and Attribution

A reporting dictionary that gives every metric a source, denominator, time window, owner and honest missing-data state.

Direct answerA dental SEO KPI is usable only when its source, formula, scope, time window, attribution rule and missing-data treatment are defined. Separate eligibility, search visibility, local-profile activity, site engagement, enquiry and attribution metrics. Report zero only when measurement operated correctly; use unavailable, pending or not applicable when the source cannot support a number.

Key takeaways

  • A dashboard tile is not a KPI until its definition is fixed.
  • Calls, direction requests and forms are interactions, not completed appointments.
  • Percentages require a defensible denominator.
  • Configuration changes belong in report annotations, not hidden footnotes.

A dashboard is not a measurement contract

Indexed pages, impressions, profile calls and booked appointments may appear in one funnel, yet each comes from a different system and proves something different. The PROOF evidence ladder establishes the sequence; the STATE contract defines each number used inside it.

The STATE KPI Contract

Source

Name the platform, property, report and accountable data owner.

Time

Fix reporting, comparison and baseline windows before reading movement.

Attribution

Document the model, lookback window, source dimension and offline rules.

Treatment

Define zero, unavailable, pending, not applicable and suppressed states.

Exactness

State the formula, filters, URL or location set and decision owner.

“Google data” is not a source. Record whether a value came from Search Console, Business Profile, analytics, call tracking, a CRM or a controlled manual observation. Freeze definitions during a reporting period and annotate any change.

Dental SEO KPI dictionary

Eligibility

Technical eligibility rate = eligible canonical URLs ÷ canonical URLs audited × 100. The audit must define “eligible,” and intentionally noindex prototypes must stay outside the denominator.

Internal-link coverage = priority URLs with at least one approved crawlable internal link ÷ priority URLs audited × 100. Valid structured-page count records pages passing syntax and visible-parity review; it proves implementation quality, not ranking.

Search visibility

Organic impressions and organic clicks come from the documented Search Console property, page set, search type, country and period. Organic CTR = clicks ÷ impressions × 100. Google’s metric definitions should govern the dashboard rather than a custom interpretation.

Observed query coverage counts classified query groups present in the chosen export and privacy threshold. Do not call it total keyword coverage because reporting and export limits apply. The target groups should connect back to the intent map.

Local visibility

Report available Business Profile interactions separately: website clicks, call interactions, direction requests and other currently exposed metrics. Do not combine them as “leads.” For local-rank observations, record the keyword, map surface, device, test point or grid, time and tool. One pin does not prove city-wide visibility. Use the local truth framework to define which real locations belong in scope.

Engagement and enquiries

Organic landing sessions are sessions beginning on measured pages and attributed to organic search under the documented analytics configuration. Measured enquiry-event rate = tested enquiry events ÷ eligible landing sessions × 100. Keep the event label until submissions have been checked against the practice’s qualified-enquiry rule.

Verified qualified enquiry count includes only genuine, relevant enquiries confirmed under that rule. Verified enquiry rate may be calculated only when numerator and denominator can be joined responsibly. Personal message contents do not belong in a public dashboard.

AI search and authority

Platform-reported AI impressions or citations use a named supported report and period. AI referral sessions measure identifiable traffic, not total citations. Verified referring-domain count includes distinct relevant domains with live qualifying links—not prospects or outreach. Link retention rate = qualifying links still live at recheck ÷ qualifying links previously verified × 100.

Protect the denominator

  • Do not divide verified enquiries by clicks when sessions represent the measured journey.
  • Do not calculate a review response rate with reviews outside the audit window.
  • Do not calculate an indexing rate from a sitemap containing intentional noindex pages.
  • Do not calculate citation share from an uncontrolled handful of prompts.
  • Do not merge paid and organic outcomes without a documented attribution reason.

If the denominator is unreliable, report the numerator and limitation instead. Precision language is more valuable than a fragile percentage.

Dashboard state and annotation contract

Each tile should show the metric name, current value or state, source, date range, comparison, scope, definition, owner, last refresh and limitation.

  • 0: measurement was available and valid; no event occurred.
  • Unavailable: required access, feature or integration did not exist.
  • Pending: collection started but the window is incomplete.
  • N/A: the metric does not apply.
  • Suppressed: the value is withheld for privacy or minimum-volume policy.

Annotate page releases, event changes, consent changes, outages and platform reporting updates. A line moving after a content launch is correlation until the measurement design supports a stronger conclusion.

Use metrics to make decisions

Eligibility metrics guide fixes. Search and local metrics guide page and profile review. Enquiry metrics guide landing-page and intake work. Attribution metrics guide budget interpretation. A useful dashboard may contain fewer numbers because every retained number has a decision owner.

Scope and limits. No KPI on this page represents a clinical outcome. Calls, forms, profile actions and visits are not patients or completed appointments. Privacy, consent and attribution configurations must be approved for the real practice and jurisdiction.
