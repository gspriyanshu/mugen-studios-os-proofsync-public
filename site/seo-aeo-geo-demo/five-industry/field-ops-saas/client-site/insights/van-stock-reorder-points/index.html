The short answer

How should a service team set van-stock reorder points?

Start with demand history, service criticality, replenishment lead time, storage limits and the cost of a missed job. Set an initial min/max rule, then review exceptions instead of treating the first number as permanent.

What this cannot decide

The framework supplies no benchmark or guaranteed stock level for a real trade or fleet.
