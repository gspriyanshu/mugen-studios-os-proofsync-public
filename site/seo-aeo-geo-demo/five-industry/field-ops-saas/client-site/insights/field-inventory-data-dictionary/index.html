The short answer

What belongs in a field-service inventory data dictionary?

Define each location, item, quantity, unit, event, job reference, actor, timestamp, source system, reason, cost treatment and exception state so operations, finance and integrations use the same meaning.

What this cannot decide

A qualified operations, accounting and technical review is required before a real data contract is approved.

Why this question is easy to misread

Search results often compress a conditional decision into one label, number or confident sentence. That shortcut is especially risky when the underlying facts change by property, product, person, programme, utility or operating model.

Use this framework as a decision record: write down the source, the observation date, the responsible owner and the limitation beside each item. That makes later review possible and prevents a polished summary from becoming an unsupported claim.
