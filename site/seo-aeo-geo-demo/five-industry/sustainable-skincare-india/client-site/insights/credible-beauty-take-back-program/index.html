The short answer

What evidence should a beauty take-back programme publish?

Publish what is accepted, where and how it is collected, the downstream processor, exclusions, the reporting boundary, period and measured results. Incentives and collection counts should not be confused with verified recycling outcomes.

What this cannot decide

The fictional take-back interface does not collect or process any package.

01

Publish eligibility before asking for empties

Customers need to know which brands, materials, product categories and pack conditions are accepted. A credible program also states whether pumps, glass, sachets, outer cartons and partially used products are included.

Preparation instructions should address emptying, rinsing, drying and safe packing without implying one routine works for every formula. The program should provide a contact route for uncertain or damaged containers.

02

Show the collection and downstream chain

A return form is only the first step. The program should identify collection coverage, logistics responsibility, consolidation and the downstream processor or processing category used for accepted materials.

When exact downstream handling varies by component, report the variation. It is better to state that mixed pumps are separated for a different route than to collapse every returned unit into a single recycled total.

03

Report dated outcomes with a visible denominator

A program report should specify the period, units or weight collected, exclusions and how the figure was verified. If the brand reports participation, it should distinguish registered requests, received parcels and accepted material.

Rewards can support participation but do not prove environmental benefit. Outcome language needs a method, while compliance under EPR remains a separate legal responsibility that should not be replaced by a voluntary consumer return campaign.
