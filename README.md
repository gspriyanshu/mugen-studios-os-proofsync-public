# MUGEN Studios OS ProofSync Public Shell

This repository is a public-safe execution shell for MUGEN Studios OS ProofSync work.

It is not the MUGEN Studios OS source authority.
It is not a proof vault.
It is not a service-readiness authority.
It is not a deployment approval.
It is not tracking approval.
It is not MCP execution approval.
It is not Route 5 approval.

## Allowed In This Shell

- public-safe documentation
- non-secret examples
- placeholder-only runtime configuration references
- synthetic fixtures after approval
- generic schemas after protection and export review
- generic validators after protection and export review
- public-safe website shell code after route and release approval

## Blocked In This Shell

- private MUGEN documents
- local private paths
- Drive identifiers
- MCP routes, logs, or outputs
- account identifiers
- client data
- screenshots, videos, frame renders, failed renders, or raw evidence
- private prompts
- atomic skill source packages
- composite service internals
- real GTM, GA4, Google Ads, Meta Pixel, LinkedIn, or Search Console identifiers
- unapproved demo, sales, portfolio, marketplace, or client assets

## Operating Rule

Every public change must be small, reviewable, reversible, and public-safe. If a change needs private evidence, Stage 2 lineage, MCP output, Drive storage, or service-specific internals, it belongs in the private system first and may only appear here as a reviewed derivative.
